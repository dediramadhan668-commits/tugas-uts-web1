# 🦸‍♂️ Toko Buku Online - Tema Boku no Hero Academia

Proyek ini dibuat untuk memenuhi **Tugas UTS Pemrograman Web 1**.  
Aplikasi web ini merupakan simulasi toko buku online berbasis **HTML, CSS, dan JavaScript**  
dengan gaya desain **Boku no Hero Academia (BNHA Theme)** — penuh warna, semangat, dan interaktif.

---

## 🚀 Fitur Utama
1. **Login System**
   - Validasi email dan password dari file `data.js`
   - Efek animasi “PLUS ULTRA” saat login berhasil
   - Modal box untuk *Lupa Password* dan *Daftar Akun Baru*

2. **Dashboard**
   - Greeting otomatis sesuai waktu (Pagi, Siang, Sore, Malam)
   - Navigasi ke halaman Stok, Pemesanan, dan Tracking
   - Desain menu hero-style interaktif

3. **Stok Buku**
   - Data katalog ditampilkan dinamis dari `data.js`
   - Bisa menambah data buku langsung dari form (DOM Manipulation)
   - Tampilan tabel rapi dan responsif

4. **Checkout / Pemesanan**
   - Form informasi pemesan & metode pembayaran
   - Data buku diambil dari katalog
   - Tabel ringkasan dan total harga dihitung otomatis

5. **Tracking Pengiriman**
   - Input nomor DO (Delivery Order)
   - Menampilkan detail ekspedisi dan status pengiriman
   - Progress tampil dengan gaya heroik (warna & animasi)
